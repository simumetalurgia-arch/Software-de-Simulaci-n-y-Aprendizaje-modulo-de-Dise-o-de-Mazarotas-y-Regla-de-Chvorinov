# Software-de-Simulaci-n-y-Aprendizaje-modulo-de-Dise-o-de-Mazarotas-y-Regla-de-Chvorinov
Herramienta interactiva diseñada para calcular el tiempo total de solidificación de piezas coladas y dimensionar mazarotas cilíndricas y esféricas en 3D. Permite trabajar en Sistema Internacional (cm) y Americano (in), previniendo defectos por rechupe mediante la igualación térmica entre pieza y alimentador.
